# Kubernetes Skill

Use when deploying/managing containerized apps on Kubernetes. Covers workloads, networking, storage, config, security, observability.

## Scope
- Workloads: Pods, Deployments, StatefulSets, DaemonSets, Jobs/CronJobs
- Networking: Services, Ingress, NetworkPolicies
- Config: ConfigMaps, Secrets
- Storage: PV/PVC, StorageClasses
- Security: RBAC, Pod Security Standards, service accounts
- Helm, Kustomize

## When to apply
- User asks about K8s manifests, debugging, or cluster operations
- Prefer declarative manifests; least privilege; resource limits
