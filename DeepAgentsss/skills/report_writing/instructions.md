# Report Writing Instructions

## Structure
1. Title (short, descriptive)
2. Executive summary (2-4 sentences)
3. Key findings (bulleted, evidence-backed)
4. Recommendations (prioritized, actionable)
5. Next steps / owners & timelines
6. Appendix (code, configs, references)

## Style
- Lead with the answer; avoid fluff
- Use concrete numbers and examples
- Keep paragraphs short; prefer bullets
- Mark assumptions and limitations explicitly
- Include code snippets in fenced blocks

## Quality checks
- Does it answer the user's actual question?
- Are recommendations feasible and prioritized?
- Is there a clear next action?
