# AWS Skill

Use when designing, deploying, or troubleshooting AWS solutions. Covers core services, IaC, security, cost.

## Scope
- Compute: EC2, Lambda, ECS/EKS, Fargate
- Storage: S3, EBS, EFS
- Data: RDS, DynamoDB, Redshift
- Networking: VPC, ALB/NLB, Route53, CloudFront
- Security: IAM, KMS, Secrets Manager, WAF
- IaC: CloudFormation, CDK, Terraform

## When to apply
- User asks about AWS architecture, deployment, or debugging
- Prefer least-privilege IAM, managed services, cost-awareness
