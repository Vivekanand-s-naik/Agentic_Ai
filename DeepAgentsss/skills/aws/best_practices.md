# AWS Best Practices

- Never hardcode credentials; use IAM roles
- Enable MFA on root and privileged users
- Least privilege; scope IAM to specific resources
- Encrypt data at rest and in transit
- Use CloudWatch alarms and dashboards
- Automate backups and test restores
- Use infrastructure as code; no manual console changes in prod
- Review cost monthly; set budgets/alerts
- Keep AMIs/images patched
