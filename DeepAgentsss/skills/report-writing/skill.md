# Report Writing Skill

Use when the deep agent produces a final answer/report. Ensures structured, clear, actionable output.

## Scope
- Structure: title, summary, findings, recommendations, next steps
- Tone: concise, professional, evidence-based
- Formatting: headings, bullets, code blocks, tables

## When to apply
- Always apply when generating final user-facing reports/answers
- Include sources/assumptions when relevant
