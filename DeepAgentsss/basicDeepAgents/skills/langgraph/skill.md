# LangGraph Skill

Use when building stateful agent workflows with LangGraph. Covers graphs, nodes, edges, state, checkpointing, human-in-the-loop.

## Scope
- StateGraph, nodes, conditional edges, cycles
- State schemas (TypedDict/Pydantic), reducers
- Checkpointers (MemorySaver, Postgres) for persistence
- Human-in-the-loop interrupts
- Tool calling agents, subgraphs, streaming

## When to apply
- User asks to design/modify LangGraph agents or workflows
- Emphasize deterministic state transitions and observability
